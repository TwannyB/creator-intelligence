# Processed Data

Files in this directory are generated by the preprocessing notebook and are not committed to the repository.

Examples include:

- merged creator video dataset
- aggregated sales-by-video dataset
- manually reviewed shoppable-video labels
- model-ready training datasets

The preprocessing flow is:

Raw TikTok videos
+
Raw TikTok Shop orders
↓
Aggregate orders by Content ID
↓
Join to videos using video ID
↓
Identify shoppable videos
↓
Feature engineering
↓
Model-ready dataset
